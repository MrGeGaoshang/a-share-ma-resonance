# a-share-ma-resonance

> A 股多周期均线共振选股 —— WorkBuddy / CodeBuddy Skill。
> 按均线条件筛全市场，自动分层、三维打分（趋势 / 资金 / 板块），输出可筛选排序的交互式 HTML 研报。

均线向上只能描述**已经发生**的趋势。这个 Skill 不预测涨幅，它做的是：把「结构是否完整」「资金是否真在进」「板块是否在风口」三件事拆开打分，让你看清确认度高低，并为每只标的写明**失效条件**用于风控。

---

## 安装

仓库根目录就是 skill 本体，直接 clone 到 skills 路径即可（一步到位，以后 `git pull` 就能更新）：

```bash
# macOS / Linux
git clone <此仓库地址> ~/.workbuddy/skills/a-share-ma-resonance
```

```powershell
# Windows (PowerShell)
git clone <此仓库地址> "$env:USERPROFILE\.workbuddy\skills\a-share-ma-resonance"
```

装完**新开一个对话**——Skill 在会话启动时加载，当前对话不会生效。

> 目录层级必须是 `.../skills/a-share-ma-resonance/SKILL.md`。多套一层会导致技能无法被识别。

## 前置依赖

1. **通达信连接器（`tdx-connector`）**，需在插件面板安装并授权。行情数据全部来自它，Skill 自身不含数据。未授权时会提示你先授权，**不会编造数据**。
2. **Python 3.8+**。脚本只用标准库，无需 `pip install`。

## 用法

直接用自然语言触发，不需要记命令：

- 「筛一下月线和日线 5/10/30 均线都向上的股票」
- 「A股月线多头排列的票，出个报告」
- 「均线共振里，主力资金持续流入、又在热门板块的有哪些，推 5 只」
- 「把上次那份名单加上周线条件重新算」

换周期组合、换均线参数、加市值 / 涨跌幅 / 资金过滤都能复用，不用改代码。

## 它输出什么

| 模块 | 内容 |
|---|---|
| 分层 | 双共振 / 仅月线排列 / 仅日线排列 / 未排列 四档，配环形图与偏离度分布 |
| 全量名单 | 现价、涨跌幅、月线三条 + 日线三条均线数值，可点击表头排序、按结构筛选 |
| 背离标记 | 均线仍排列但当日大跌的标的自动标出，提示优先剔除 |
| 三维打分 | 趋势 35 + 资金 30 + 板块 20 − 风险 ≤15，同行业去重 |
| 精选卡片 | 分数条、三维拆解、入选理由、风险提示、**失效条件** |

## 设计取舍（为什么资金不是硬门槛）

实测叠加条件后的通过数（2026-10-30 数据）：

| 条件 | 剩余 |
|---|---|
| 双均线共振 | 112 |
| ＋ 近 5 日主力净流入 | 59 |
| ＋ 连续 3 日净流入 | 13 |
| ＋ 连续 5 日净流入 | 4 |
| 40 只双共振 ∩ 连续 3 日净流入 | **3** |

资金与趋势严重不同步。若把「持续增持」设为硬过滤，核心池只剩 3 只，失去选择余地。所以资金做成**加权维度**而非门槛。

## 已知限制

1. **滞后指标**：「均线向上」只描述已发生的趋势，无预测能力，识别不了顶部。
2. **月线未定型**：仅月末最后一个交易日收盘后当月月 K 才定型。月中运行得到的 `MA30` 是未完成月的推算值。
3. **次新股失真**：月线 MA30 需 30 根月 K，上市不足 30 个月的标的判定不可靠。
4. **分数不是涨幅预测**。模型未经胜率回测，分数表达的是「三项条件是否同时成立」，不是「能涨多少」。
