# 通达信 MCP 调用要点（均线筛选场景）

## 1. 条件选股 `tdx_screener`

| 参数 | 取值 | 说明 |
|---|---|---|
| `message` | 自然语言条件 | 复合条件写在一句里，用「且」连接 |
| `rang` | `"AG"` / `"HK-GP"` / `"JJ"` / `"ZS"` | A股用 `AG` |
| `pageNo` | 从 1 开始 | |
| `pageSize` | 默认 10 | 需全量时直接传总数 |

已验证可解析的写法：

```
月线5、10、30月均线均向上，且日线5、10、30日均线均向上
```

引擎会返回命中总数（该例为 112）与当页明细，明细中每只股票带 `sec_code / sec_name` 及六条均线数值，可直接用于分层。**不要**自己拆成「先筛月线 336 只 → 再筛日线 112 只 → 取交集」，分页拼接会漏。

## 2. K 线 `tdx_kline`

| 参数 | 常用值 |
|---|---|
| `code` | 纯数字，不带后缀 |
| `setcode` | `"1"` 沪市（6/68 开头）、`"0"` 深市（00/30 开头）、`"2"` 北交所（43/83/87 开头） |
| `period` | `"4"` 日线、`"5"` 周线、`"6"` 月线、`"10"` 季线、`"11"` 年线 |
| `wantNum` | 1~1000；月线算 MA30 取 45 根以上 |
| `tqFlag` | `"1"` 前复权（默认）、`"0"` 不复权、`"2"` 后复权 |

- `period` 默认是 5 分钟线，查日线必须显式 `"4"`，否则数据全不对。
- `code` 与 `setcode` 不匹配时返回空数据而非报错——空结果先查这两个参数。
- 复权必须与选股引擎一致（都用前复权），否则均线数值对不上。

## 3. 实时行情 `tdx_quotes`

需要现价、涨跌幅、市值、PE/PB 时使用。`hasCwInfo="1"` 一次性带出 PE/PB/ROE/市值，不必再查财务接口。批量补价时逐只调用，可并发。

## 4. 数据自检的标准做法

```
tdx_kline(code="600941", setcode="1", period="6", wantNum="45", tqFlag="1")
→ 取每根月 K 的收盘价，按时间正序写成 JSON
→ python scripts/check_ma.py closes.json
→ 对比脚本输出的 MA5/MA10/MA30 与 tdx_screener 返回值
```

已验证案例：中国移动 600941 月线 MA5 92.85→94.60、MA10 92.39→92.96、MA30 96.77→97.09，脚本复算与引擎返回值完全一致，说明引擎的「向上」= 均线数值相对上一根 K 线抬升。

## 5. 常见坑

| 现象 | 原因与处理 |
|---|---|
| 返回 0 条 | 条件过严或字面写法引擎不认；放宽条件或改「均线多头排列」表述，**不得编造名单** |
| 均线数值为空 | 该股上市时间不足，长周期 MA 无法计算 |
| 与自算差 1–2% | 复权方式不一致（引擎前复权 vs 你取的不复权），统一 `tqFlag="1"` |
| 月中筛「月线」 | 当月 MA 是未完成月，报告必须注明，或改用上一完整月判定 |
| 北交所标的 | `setcode="2"`，流通性差，均线信号可信度低，建议单列提示 |

## 6. 资金面条件（已验证）

在 `message` 里直接叠加资金条件即可，引擎能识别：

| 写法 | 命中数（叠加双均线条件后，2026-10-30） |
|---|---|
| 且主力资金净流入 | 55 |
| 且近5日主力资金净流入 | 59（返回「主力净额」为5日累计） |
| 且主力资金连续3日净流入 | 13 |
| 且主力资金连续5日净流入 | 4 |

**坑**：「主力资金净流入」是**当日**口径，不是持续。要判断「一直在增持」必须用「连续N日」或自行累加明细。

单只个股的 20 日逐日明细：
```
tdx_api_data entry="TdxSharePCCW.tdxf10_gg_jyds" fixedTag="zjlx" code="600036"
→ tables[capital_flow].rows：日期 / 主力净额金额 / 主力净额占比 / 超大单 / 大单 / 收盘价
```
「主力净额占比」= 净额/成交额，**是唯一做过市值归一化的资金指标**，跨市值可比。单日占比异常（如 >30%）通常是事件驱动，不能当持续建仓。

## 7. 板块热度（关键技巧）

| 写法 | 结果 |
|---|---|
| `rang="AG"` + 「近5日涨幅居前的行业板块」 | ❌ 被解析成**个股**排行，但会带出每只股的「所属通达信研究行业」，可反查行业 |
| `rang="ZS"` + 「近5日涨幅居前的行业指数」 | ✅ 返回 **881xxx 行业指数** + 5日涨幅 + 排名，共 100 个 |

`rang="ZS"` 是唯一能拿到板块涨跌排行的路径。返回的 `sec_code` 可直接用于 `tdx_kline(code="881006", setcode="1", period="4")` 取板块 K 线。

## 8. 个股行业归属

```
tdx_api_data entry="TdxSharePCCW.tdxf10_gg_gsgk" fixedTag="0" code="601857"
→ basic_info.rows[0]["通达信研究行业"] = "石油—油气开采"
```
破折号后的二级行业名（`油气开采`）与行业指数名称一致，可直接匹配。**注意**：`tdx_indicator_select("某股 所属行业")` 会误命中港股同一公司（招商银行返回 03968 的港交所行业），不要用它取 A 股行业。

## 9. 板块阶段涨幅接口的坑

`TdxSharePCCW.skef10_bk_cpbd_jczl branch="003" code="881234"` 返回**空表**（需特定时间参数），不要依赖。板块涨幅一律走 `rang="ZS"` 的选股接口。
